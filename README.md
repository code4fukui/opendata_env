# Open Data for Sabae City Environmental Hackathon (opendata_env)

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

`鯖江市環境ハッカソン参考オープンデータ`

Open data and reference materials for the "Protect the Environment Hackathon in Sabae" (2022/12/17-18), hosted by Fukui Prefecture and supported by Sabae City.

**Event Details:** [『守る環境ハッカソンin鯖江』～次世代に残そう美味しい越前ガニ～ | Peatix](https://peatix.com/event/3412028)

## Live Demos
A collection of applications built using the data in this repository.

- **[Waste Disposal Navigation (ごみすてナビ)](http://odp.jig.jp/gomisute/)**: A guide for waste disposal.
- **[Is it Recyclable Paper? Quiz](https://code4fukui.github.io/yesnoquiz/zatsugami_or_not.html)**: A quiz to help identify recyclable paper (`雑がみ`).
- **[Waste Classification Data Viewer (Sabae & Mishima)](https://fukuno.jig.jp/app/odp/gomiclass.html)**: An app for browsing waste classification data.
- **[Waste Incineration Game (Sabae Edition)](https://code4fukui.github.io/gomiq/)**: A game about waste incineration.
- **[Monthly Waste Collection Data Viewer](https://code4fukui.github.io/opendata_env/gomi-amount-sabae.html)**: An interactive table showing monthly waste collection volumes, powered by live ODP data.
- **[Fukui Prefecture Incinerator Map & List](https://code4fukui.github.io/opendata_env/incinerator-fukui.html)**: A map and sortable list of incineration facilities in Fukui.
