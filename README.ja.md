# 鯖江市環境ハッカソン用オープンデータ (opendata_env)

`鯖江市環境ハッカソン参考オープンデータ`

福井県主催、鯖江市協力の「守る環境ハッカソンin鯖江」（2022/12/17-18）向けのオープンデータおよび参考資料です。

**イベント詳細:** [『守る環境ハッカソンin鯖江』～次世代に残そう美味しい越前ガニ～ | Peatix](https://peatix.com/event/3412028)

## ライブデモ
このリポジトリのデータを活用して構築されたアプリケーションのコレクションです。

- **[ごみすてナビ](http://odp.jig.jp/gomisute/)**: ごみの処分方法を案内するアプリケーション。
- **[クイズ雑がみか否か](https://code4fukui.github.io/yesnoquiz/zatsugami_or_not.html)**: 雑がみを識別するためのクイズ。
- **[ごみ分別データビューア（鯖江市＆三島市）](https://fukuno.jig.jp/app/odp/gomiclass.html)**: ごみ分別データを閲覧するアプリ。
- **[ごみ燃やしゲーム（鯖江編）](https://code4fukui.github.io/gomiq/)**: ごみ焼却に関するゲーム。
- **[月別収集量表示アプリ](https://code4fukui.github.io/opendata_env/gomi-amount-sabae.html)**: 月別のごみ収集量を表示するインタラクティブな表（ODPライブデータ連動）。
- **[福井県焼却施設マップ＆一覧](https://code4fukui.github.io/opendata_env/incinerator-fukui.html)**: 福井県内の焼却施設を表示するマップとソート可能な一覧。
